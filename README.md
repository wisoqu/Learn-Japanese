# kana.app

Приложение для изучения японского: **хираганы**, **катаканы**, позже — кандзи.

Сделано как продукт, а не как урок: строка за строкой, анимация strokes, практика
письма по контуру, система повторения и чат с помощником. Frontend — статический сайт
без сборщика, backend — крошечный FastAPI. Frontend работает и без backend: прогресс
лежит в localStorage.

---

## Быстрый старт

```bash
./run.sh              # сервер: статика + /api + прокси Gemini → http://localhost:10001
./run.sh --static    # только static-сервер, без backend
```

Специально:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r server/requirements.txt
uvicorn server.app:app --host 0.0.0.0 --port 10001
```

Без сервера:

```bash
python3 -m http.server 10001 --directory app
```

Проверка, что всё работает:

```bash
./test.sh
```

## Как устроено обучение

### Строки (lines)

Кана разбита на **строки** — это строки таблицы 五十音. Каждая строка — один шаг:

1. Показывается строка символов (あ行 → あ い う え お).
2. Для каждого символа — произношение, анимация strokes и практика письма.
3. Потом строка уходит в колоду, и карточки开始 смешиваться.
4. **Когда строка пройдена больше на половину**, открывается следующая.

Последующие строки включают предыдущие в колоду повторения — то есть в review всегда
попадают и старые символы, а не только новая строка.

### Повторение (SRS)

Над каждым символом ведётся собственная карточка с состоянием и интервалом
(адаптированный SM-2):

| Ответ    | Эффект                                            |
|----------|---------------------------------------------------|
| `5` — идеально | интервал удваивается через ease-фактор          |
| `4` — хорошо    | интервал растёт медленнее                        |
| `0–3`   | интервал сбрасывается до 10 минут, ease снижается |

Символ считается **усвоенным** (`mastered`), когда прошёл ≥3 удачных повторения
с интервалом ≥2 дня. Уровень строки — это средняя величина по её символам
(0 = не встречен, 1 = видел, 2 = учится, 3 = усвоил), и **следующая строка открывается
при уровне ≥0.5** — «больше на половину», как и хотелось.

Новые символы попадают в колоду с лимитом `newPerDay` (по умолчанию 10), чтобы
сессия не превращалась в поток новых карточек.

### Тип карточки по наступлению

- `read` — «как это читается?», выбор из 4 ромаджи
- `write` — «напиши символ», рисование на canvas
- `type` — «как это пишется?», ввод ромаджи

Сначала даётся только `read`, потом `write`, и только после того как символ
уже несколько раз встретился — добавляется `type`.

### Оценка письма

Канвасы с пользователем сравнивается с образом из KanjiVG по трем числам:

- **coverage** — сколько strokes из образа покрыли (вес 0.62)
- **precision** — насколько рисунок совпадает с нужным, без лишнего (вес 0.38)
- **direction** — насколько следовали strokes в правильном порядке (бонус 0.14)

Оценка от 0 до 1: ≥85% — «отлично», ≥65% — «хорошо», ниже — «попробуйте ещё раз».

## Чат

Чат выключен по умолчанию. Он включается, когда пользователь вводит
Gemini API ключ в настройках — ключ хранится только в браузере и уходит через
сервер-прокси, а не напрямую из консоли.

```
POST /api/chat   X-Gemini-Key: …   →  SSE-поток ответа
```

Если backend недоступен, чат просто показывает сообщение «ещё не подключён» —
остальное приложение не ломается.

Модель по умолчанию: `gemini-2.0-flash`. В настройках можно ввести другую.

## Добавление кандзи

Не нужно писать ни одного SVG вручную. Скопируйте нужные файлы из KanjiVG
(`kanji/<hex>.svg`, где hex — codepoint символа без ведущего нуля), добавьте символ
в таблицу и строку в `tools/generate_data.py`, затем:

```bash
python3 tools/generate_data.py --source tools/kanjivg-src --out app/data/kana.json
```

Данные для кандзи нужны ровно такие же — KanjiVG хранит их в том же формате.

## Добавление языка интерфейса

Добавьте словарь в `app/js/i18n.js` и занесите его в `LANGS`. Ни один экран
переписывать не нужно — все подписи идут через `t("ключ")`.

## Android

Frontend не нуждается в сборке, поэтому для Android достаточно обернуть `app/`
в WebView или Capacitor. Recommendation: Capacitor, потому что он умеет
доступ к filesystem и canvas без доработок. При этом прогресс в localStorage
перейдёт в файл приложения — для Android нужен явный экспорт/импорт (клавиш
уже есть в настройках).
